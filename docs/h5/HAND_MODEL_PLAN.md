# H5 手部建模准备（分支 cursor/h5-with-handmodel）

基准：与线上 Pages 一致的 `docs/h5/drill-cam-v1.0.html`（main @ d0372af / Safari 分享版）。

## 目标
在现有 PoseLandmarker（全身姿态）之上，增加 **手部关键点**。手部只用于双手入镜门；画面上手模改为固定车道前后推（不再跟腕点）。寸劲辉光与「寸劲到位」短签已去掉；木人臂命中闪光／音字保留。

摄像头路径点「开始」后，须由 HandLandmarker 在同一帧里同时检出左手与右手才开课。日课无摄像头时可直接开课，用 F／J 或触控演示驱动。触控演示可以不经过双手门。

## 建议接口（本阶段只定方向，不定死数值）
1. 模型：MediaPipe Hand Landmarker（或 Pose+Hands 组合），与现有 `tasks-vision` 同栈。
2. 加载：CDN 优先，本地 `docs/h5/mediapipe/` 后备；失败时日课触控演示仍可用。
3. 与玩法：摄像头路径须同帧检出左右手才开课；日课无摄像头可直接开课；触控演示／F／J 可绕过双手门。HandLandmarker 只做双手入镜门；Pose 独掌 `ArmShape` 与命中（左臂只判冲、右臂只判膀）；手模不进入判定、不改置信度。手模前后推由 Pose 本侧结果或 F／J／触控脉冲驱动。
4. 渲染：前臂中段到指尖的皮肤贴图（透明 PNG，长边不超过 512），画在固定车道上（左手在杆左、右手在杆右），用 `push` 指数平滑前后推；不再跟腕点、不左右翻转、无掌倾、无寸劲辉光。横屏可见长度约视口宽度的 1/3；竖屏停在中臂与右上靶臂之下。叠层低于木人高亮靶臂。

就绪先分 `need_both` 与 `both_ready`（或等价名）。`both_ready` 之后，`HandPresent`∈{`guard`,`punch_drive`,`bong_bridge`,`lost`}。`need_both` 在开了摄像头时不画挡住木人的手模。动作语义：左臂／F＝冲，右臂／J＝膀。

## 表现层落地（本分支，未合 main）

`docs/h5/drill-cam-v1.0.html` 已接上表现层。`HOLD_PASS_MS`、击后冷却、60s 与十击谱未改。Hand 不进入 `classifyPose`，不写 `confidence`。

- 加载：摄像头权限成功后的同一条 `initPose` 路径创建 HandLandmarker，且不阻塞开课。模型先取 Google 存储 CDN，再试 `docs/h5/mediapipe/hand_landmarker.task`。失败或仍在下载时，Pose 日课与触控演示继续。
- 同帧：视频 `currentTime` 变化时取一个时间戳，同时交给 Pose 与 Hand。不把上一帧手点配到本帧姿态。
- 车道：左手固定在杆左侧、右手在杆右侧（杆中线约 `0.58w`），角度略向内不交叉。每只手一个 `push`（0 护手 → 1 前推并缩小约 15%）；正在出招的手前推，另一只留在护手位。
- 平滑：`push` 以约 90ms 时间常数指数靠近目标。无摄像头调试脉冲为前推约 180ms、停 150ms、回收 250ms。开摄像头时由 Pose 本侧达标驱动目标 1／0，不用 Hand 的左右标签推车道。
- 画面：皮肤精灵画在 `#handOverlay` 固定车道上。横屏可见前臂加手的长度约为视口宽度的 1/3；竖屏只占用中臂与右上靶臂下沿以下的空档。`armRU`／`arm.mid` 高亮的 `z-index` 仍压过虚手。摄像头小窗只画本侧 Pose 关节点。无寸劲辉光。
- 丢手（仅开摄像头后）：单帧漏检先留短暂宽限。缺一手显示「请双手入镜」并软暂停；两手都没了显示「手模丢失，回到框内」。未开摄像头时日课一直画护手位双手。
- 双手门：摄像头日课点「开始」后须同一帧左右手才开课。日课无摄像头（权限失败／未开）直接开课，可用 F／J／触控。触控演示不经双手门。
- 皮肤：`docs/h5/hand-skin-L.png`、`docs/h5/hand-skin-R.png`，前臂中段到指尖，最长边 512。护手／冲／膀共用，靠 `push` 区分。

页面已按下一节口径接上。`both_ready` 在页面里记为 `both`。缺左、缺右记为 `miss_left`、`miss_right`，短签仍是「请双手入镜」。还没双齐时，两手都不在记为 `need_both`。

## 手模 ↔ 摄像头同步口径（对照 FPV 参考图）

1. 同源同帧：同一视频帧同时跑 PoseLandmarker 与 Hand Landmarker。用手部结果时必须带同一视频时间戳，禁止用手部上一帧去配姿态本帧。双手入镜门也用这一帧的 HandLandmarker 结果：左手与右手必须出现在同一帧。
2. 驱动分工：Pose 负责冲／膀二形与命中（左臂只冲、右臂只膀；瞬时或维持 3s、冷却 2s、60s 十击谱不变）。Hand 的 21 点只做双手入镜门，不驱动手模根位，不另开命中通道。手模 `push` 由 Pose 本侧或 F／J／触控脉冲驱动。
3. 空间映射：手模在固定车道上前后推，不再跟腕点。手点丢失（开摄像头后）时手模隐藏；无摄像头日课与触控／F／J 仍可用。
4. 画面层：手模叠在摄像头预览之上，不得遮挡木人高亮靶臂（armRU／arm.mid）与中线。竖屏和宽度不足 1000px 的横屏保持 420 单栏。更宽的横屏用左栏、舞台、右栏；桩臂以杆中线为根。请双手入镜、手模丢失、出招手短签靠边，不压中线。无手模寸劲辉光。
5. 模式边界：参考图中「10 秒内击打右上桩手 10 次」是另一套节奏表，可共用同步层，但不得改当前木人桩课 60s／3s／2s。未过线前不合 main、不刷 Pages。

## 制片冻结：双手入镜门与就绪态

以下口径已冻结，并已写进 `docs/h5/drill-cam-v1.0.html`。

1. 摄像头日课的「开始」：同一帧 HandLandmarker 同时给出左手与右手才开课。只看到一只手、两只落在同一侧、或左右手分属相邻帧，都不开门。日课无摄像头直接开课。触控演示／F／J 不走这道门。
2. `need_both`（开了摄像头时）：跟踪不足左右各一只。短签为「请双手入镜」。此态不画挡住木人的手模，软暂停不计击。
3. `both_ready`（或等价名）：同一帧左手与右手都在。摄像头开课解锁。之后车道呈现：`guard`／前推冲／前推膀／`lost`。
4. 课中再丢一只手：软暂停，短签「请双手入镜」，手模隐藏。双手重新入镜后续上。Pose 仍独掌 `ArmShape`、命中、`confidence`、维持 3s、冷却 2s、60s 十击。
5. 曾经 `both_ready` 之后双手都离开：呈现记为 `lost`，短签「手模丢失，回到框内」。不推进步骤下标；双手回到后再续。还没到过 `both_ready` 时双手都不在仍算 `need_both`。
6. 单帧漏检不立刻改短签。去抖结束后仍不满足左右手，再进入上面的 `need_both` 或 `lost`。

同帧时间戳、Pose 独掌命中（左冲右膀）这两条不变。

## 叙事短签（HandPresent → 文案）

短签只走 FxLayer，不改 Pose／Hit 判定。口令：「左手斜上冲出／右手斜下成式」。

- `need_both`：「请双手入镜」。
- `guard` 且双手已就绪（或无摄像头护手）：无短签。
- 左手前推中：「左手 · 日字冲拳」。
- 右手前推中：「右手 · 膀手」。
- `lost`（就绪之后双手都离开）：「手模丢失，回到框内」。
- 计击瞬间：不再显示「寸劲到位」；木人臂闪光／音字仍在。
